# 🚀 Astro Digital — Landing Page & Portfólio de Alta Conversão

Landing page profissional e moderna criada para a **Astro Digital** (Criação de Sites Profissionais, Landing Pages de Alta Conversão e Presença Digital).

---

## ✨ Recursos & Diferenciais

- 💎 **Design Luxury Tech:** Estilo visual inspirado nas melhores empresas de tecnologia (Apple, Linear, Vercel).
- 📱 **100% Responsivo:** Otimização Mobile-First para smartphones, tablets e desktops.
- ⚡ **Alta Performance:** Carregamento ultra rápido com Tailwind CSS e código otimizado.
- 📲 **WhatsApp Conversion Engine:** Roteamento de mensagens personalizadas direto para o WhatsApp oficial.
- 📂 **Catálogo de Modelos (`modelos.html`):** Demonstrações reais de nichos como Saúde/Clínicas, Advocacia, Vendas & Mentorias, Gastronomia, Engenharia e Imobiliárias.
- 🖼️ **Modal Lightbox:** Visualização interativa dos mockups de projetos.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**
- **Tailwind CSS (CDN)**
- **JavaScript Moderno (ES6+)**
- **Font Awesome 6 & Google Fonts (Outfit, Plus Jakarta Sans, Space Grotesk)**
- **Node.js (Servidor local estático)**

---

## 🚀 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/savantsurf-arch/Astrodigital.git
   ```
2. Abra a pasta do projeto e inicie o servidor:
   ```bash
   node server.js
   ```
3. Acesse no navegador:
   ```text
   http://localhost:8080
   ```
   *(Ou dê dois cliques no arquivo `iniciar-site.bat` ou abra diretamente o `index.html`)*
